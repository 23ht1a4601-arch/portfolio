- *Verified Platform:* SkillWallet Lifecycle Tracking

---

## 📌 Project Overview
The *Medical Diagnosis Center by Service Portal* is a digital health tech solution built on the *ServiceNow* platform. The system completely digitizes and automates patient record lifecycles, appointment bookings, and lab workflow communications. It provides high-efficiency service portals for patients, internal clinical specialists, and support administrators to seamlessly handle medical service requests.
